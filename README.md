# The Watching Windmill 🎮

**A free, atmospheric first-person horror game demo made with Godot 4.6.**

### [▶ Play the free Windows demo on itch.io](https://retro0o0o.itch.io/the-watching-windmill)

## About

*The Watching Windmill* is an independent first-person horror demo focused on dark environments, exploration, suspense, and an unexpected encounter. It began as a personal project in August 2025, was paused during university, and was later revisited and released as a playable demo in 2026.

## Development highlights

- First-person exploration and interactions in a 3D horror environment
- Flashlight and atmosphere-focused gameplay
- Monster-triggered horror sequence and seamless jumpscare presentation
- Optimized scene transitions using threaded resource prefetching
- Rendering warmups to reduce first-use stutters
- Custom Main Menu and cinematic intro sequence

## Built with

- **Engine:** Godot 4.6
- **Scripting:** GDScript
- **Platform:** Windows (downloadable demo)
